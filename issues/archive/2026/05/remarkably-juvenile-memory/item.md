# issuectl open <slug> — editor integration

## Description

'issuectl open <slug>' opens item.md in $EDITOR (or --editor code / --editor zed). Also 'issuectl open --dir <slug>' opens the issue directory. Tiny but highly used; the issue is a real file, leverage that.
