# Cycles / iterations (Linear-style lightweight planning)

## Description

Optional 'cycle' frontmatter (e.g. 'cycle: 2025-W07'). Commands: 'issuectl cycle current', 'issuectl cycle plan 2025-W08', 'issuectl cycle status'. Reporting rolls up open/closed counts per cycle. Lighter than Jira sprints; no server. Useful for small teams that want time-boxed planning without adopting heavyweight tooling.
