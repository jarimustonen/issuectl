# Document or revisit two-value priority schema (only normal/high; no low/medium/critical)

## Description

Many trackers default to low/medium/high or low/normal/high/critical. 0.5.1 allows only normal/high. Discussion point, not a bug: if intentional, document the rationale in schema docs and 'issuectl new --help'. If not, consider allowing low. See @intensely-ill-garden for full feedback context (3DBear monorepo 0.3.1 → 0.5.1 migration, 2026-05-10).
